# Install (for Claude Code)

1. Copy this whole folder (`fullscreen-talking-head-edit`) into `~/.claude/skills/` (Windows: `C:\Users\<you>\.claude\skills\`), or into the project's `.claude/skills/` folder.
2. Restart Claude Code. The skill loads when you ask for a talking-head or VSL edit with graphics, the "blue" look, or graphics without a split screen.
3. `reference/kit.tsx` is a drop-in Remotion/React file: icon tiles, flat discs, glass cards, default avatar, colour helper.
4. To review cuts frame by frame, set up the Review Desk from the other zip and deliver every render through it.
